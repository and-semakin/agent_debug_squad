# v0.24.0

## Breaking: ZCode backend deprecated and removed

The experimental ZCode backend depended on private Desktop internals. Repeated
changes to registry initialization and host callbacks required adapter repairs.
The latest observed failure, with Desktop 3.19.0, was
`CREDENTIAL_SECURE_STORAGE_UNAVAILABLE` in Squad's separate Node host even while
Desktop could use the existing login. This is an integration failure, not evidence
that the user's Desktop account is invalid. The private adapter, bridge, fixtures,
example, and research probe are removed rather than maintained further.

- Remove the `zcode` section from `~/.agent-debug-squad/backends.yaml`, even if empty.
- Replace ZCode agents with a supported backend: Codex, Cursor, Kimi, OpenCode 1,
  OpenCode 2, or official Devin CLI. Configure that backend's own options and login.
- Start a fresh Squad session using a new session name or state directory. Old
  native conversation IDs cannot migrate; existing artifacts are left intact.
- `models --all` no longer includes ZCode. Explicit `--backend zcode` fails with
  migration guidance. Stale agents and machine sections fail validation early.

The ZCode skill installation host remains available and is independent of backend
execution. Other backend protocols and release archive names are unchanged.
